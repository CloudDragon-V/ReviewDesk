# 其它文件怎么找

- **安装新版软件**：打开 `安装包`，双击 `ReviewDeskReading-0.2.0-Setup-win-x64.exe`。
- **直接运行新版**：打开 `运行文件/ReviewDeskReading/ReviewDeskReading.exe`，此目录的其他文件也需保留。
- **查看完整示例**：`示例说明书/购物订单_详细代码说明书.md`，约1.9万字符。
- **旧版软件**：`ReviewDesk-0.1.0-*` 是经典版，`ReviewDeskReading-0.2.0-*` 是当前新版。
- **阅读项目说明**：打开 `README.md`；设计和运行细节在 `需求规则目录`。
- **验证和测评**：`tests` 是应用测试；`evaluation` 是模拟盲评；`verification` 是运行结果和证据。
- **维护与打包**：`scripts` 是辅助脚本，`packaging` 是安装配置，`licenses` 是第三方许可。
- **开发环境**：`.venv` 是 Python 环境，`.tools` 是编译工具，`.idea` 是 PyCharm 配置，`构建缓存` 是中间产物。
