PyCharm 解释器改选 `其它/.venv/Scripts/python.exe`，运行 `前端功能/app.py`。安装用户直接使用 `其它/安装包/ReviewDesk-0.1.0-Setup-win-x64.exe`；复制到另一台电脑不需要复制开发环境。原盲评文件中的旧路径保留为历史证据，回放工具已适配新位置。

## 职责和调用链

| 文件 | 当前职责 |
|---|---|
| `前端功能/app.py` | QApplication、窗口、独立冒烟入口 |
| `后端功能/reviewdesk/models.py` | SourceFile / Finding / GraphNode / GraphEdge / Analysis / Context / Usage / ReviewResult 数据类 |
| `analysis.py` | 有界只读扫描、编码识别、AST规则、静态定义/调用/导入图 |
| `context.py` | 常见敏感值脱敏、保守预算、截断与依赖策略、提交行allowlist |
| `api.py` | 官网HTTPS、禁止带凭据跟随重定向、超时/错误转换、token校验、有日期单价 |
| `service.py` | 综合/分类审查、费用预检、候选校验、结果合并、报告导出 |
| `storage.py` | Windows系统凭据、每次操作独立连接的SQLite报告存取 |
| `前端功能/reviewdesk_ui/ui.py` / `widgets.py` | 中文界面、后台任务、代码与关系图、历史、设置、人工状态 |

表中未写全路径的业务模块均位于 `后端功能/reviewdesk/`。

界面发送前展示快照预览；后台在同一个快照上构建上下文与调用API，不执行被审查代码。静态结果来源 `static`，模型结果来源 `llm`。混合报告 `mode=hybrid`；API失败的报告 `mode=partial`，本地报告 `mode=local`。

## 实际数据格式

统一以 `models.py` 为准，采用标准库 dataclass，未引入 Pydantic。路径是项目相对路径，行号从1开始。Finding 的类别是 correctness/redundancy/optimization，严重程度 critical/high/medium/low/info；类别不是严重等级。用户状态 new/accepted/dismissed。

ReviewResult 带 `schema_version=1`、项目名、时间、发现列表、局限、真实用量字段、字符串形式的 Decimal 费用和源文件哈希；不保存完整源码。SQLite当前 `user_version=1`，reports表按JSON存储版本化报告。未实施云同步。

`Context.included_spans` 是外部结果的行号允许范围；路径必须属于本次输入，引用行必须在实际提交范围内，摘录必须匹配源码和已发送内容。校验通过只代表位置与摘录有依据，不代表模型的逻辑判断一定正确。

## 安全、费用和存储

密钥：调用 Windows CredWriteW/CredReadW/CredDeleteW，目标 `ReviewDesk/DeepSeek`，只属于当前用户。没有明文文件回退，安装包也不包含密钥。

数据库：`%LOCALAPPDATA%/ReviewDesk/reviews.db`。`REVIEWDESK_DATA_DIR` 可用于隔离测试；安装目录无需写权限。报告含必要证据与路径，用户可自行管理本机历史数据。

费用：2026-09-12核查官网Flash/Pro模型，按API返回的输入、缓存命中与输出token计估算人民币费用，区分工作日高峰与空闲时段。发送前预检以高峰单价和保守预算代理计算，默认单次上限0.20元、输出上限2500token、无自动收费重试。服务器超时/缺失usage时显示未知；不能把零数值当实际零消费。

研究评估：隐藏题库作者先冻结题目与答案哈希，候选代码冻结后采集匿名结果，独立评分者不知道候选来源，再揭盲计算精确率/召回率/F1。共享模型家族与环境不构成严格人类双盲，结论仅限本次合成样本。
