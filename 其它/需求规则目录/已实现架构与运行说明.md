# ReviewDesk 0.2 已实现架构与修改入口

更新：2026-09-29（源码修补版，现有安装包尚未重建）。这里只描述实际实现；经典版见同目录“经典版0.1架构说明.md”。

```mermaid
flowchart LR
  A[Windows 快捷方式] --> B[ReviewDeskReading.exe]
  B --> C[127.0.0.1 FastAPI]
  B --> D[默认浏览器 Vue]
  D --> C
  C --> E[Python AST 语言适配器]
  E --> F[(SQLite 知识库)]
  F --> G[词项 符号 调用关系检索]
  E --> H[完整静态说明]
  G --> I[发送预览 费用检查]
  I --> J[DeepSeek 详细讲解]
  H --> K[说明书持久化]
  J --> K
  K --> L[超过5000字自动 Markdown]
```

程序是本机浏览器界面，安装包携带 Python 与 Vue 静态文件；Node 仅开发构建使用。FastAPI 监听 IPv4 环回地址，使用随机会话 token、Host/Origin 检查和 JSON 约束。它不是互联网多用户服务器。

## 数据流与可验证边界

导入：Vue 提交相对路径与源码或用户选择的目录 → 路径/语言/容量校验与常见密钥脱敏 → AST 分析和静态 findings → 单次事务保存项目版本、源码、符号、调用与索引。按 revision_id 读取、检索、讲解、对比，避免跨版本混入证据。同名同内容且分析器/索引版本相同才复用版本；分析器或索引升级后再次导入会建立新快照，旧数据不覆盖。完全相同内容的一对一文件改名才自动识别。

讲解：完整 Program 生成静态说明 → 当前版本检索并按预算选证据（按文件/行区间扣除已发送部分）→ E 编号、覆盖/遗漏区间与实际文本预览 → 有效10分钟的一次性 preview_id → 文档容量预检 → 单次 DeepSeek 调用 → 校验章节引用 → 正文与用量先提交 SQLite → 超5000非空白字符再自动写 UTF-8 Markdown。导出失败保留数据库正文，下载不依赖导出文件；重试导出只重写文件，不调用模型。数据库自身不可写仍可能无法保存新正文。模型失败不自动重试；缺少用量标记未知；引用有效不等于逻辑必然正确。

源码联动：本地 `source_reference()` 将静态位置或校验通过的 E 编号转成 `reviewdesk-source:` 引用；模型自行生成该协议的内容会被中和。前端校验路径与行号，再按说明书的 `revision_id` 读取原始快照，而非当前项目的同名文件。找不到原版本/文件/行号时明确报错。旧报告原文保持不变，重新生成后才能获得新的可点击引用。

任务恢复：顶部“近期任务与中断记录”读取最近20项任务及独立的用量收据；服务重启将未结束任务标记为中断。已提交但未取得实际用量的请求提示核对平台账单，不自动补发，不按零费用展示。

默认数据在 `%LOCALAPPDATA%\ReviewDesk`：`knowledge.db` 保存脱敏源码全文和结构，`workbench.db` 保存任务/说明/usage_receipts，`manuals/` 保存长文。旧 `reviews.db` 保留。密钥存在 Windows Credential Manager `ReviewDesk/DeepSeek`。删除本机项目不修改源代码。

没有 MySQL、Redis、Docker、向量数据库或嵌入模型。RAG 检索层是词项与结构检索；模型只获得预览内证据。Python 代码只解析，不执行；变量事件不能解释成实时运行值。

## 语言扩展与测试

其它语言适配器需实现 `LanguageAdapter` 协议，输出统一 Program 的 files、symbols、calls、entry_points、limitations；还需实现扩展名、目录扫描、前端选择和专属语义测试。当前只预留接口，没有实现其它语言解析器。

Python 测试：将 `PYTHONPATH` 设为 `后端功能;前端功能`，执行 `python -m unittest discover -s 其它/tests -v`。

前端：`前端功能/web` 中执行 `npm ci`、`npm test`、`npm run build`，使用 package-lock 锁定依赖。

集成入口：`前端功能/workbench.py --no-browser --data-dir <隔离目录> --smoke-test <结果.json>`；冻结 EXE 接受相同参数，实际通过 HTTP 导入、生成、保存、下载和检查前端服务。

盲评初始输出保持冻结；看到题目或评分后修复只算回归，不重新宣称未见样本。全部验证入口见 `其它/verification/v0.2验收报告.md`。
