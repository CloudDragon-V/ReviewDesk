# ReviewDesk 0.2 实施与验收报告

日期：2026-09-20。范围：Windows 本机代码阅读工作台，内置 Python 语言支持，Vue + FastAPI + SQLite + 代码证据检索增强讲解。最终交付文件位于 `其它/安装包/`；程序源代码继续按“前端功能 / 后端功能 / 其它”分类。

## 1. 用户要求对应实现

| 要求 | 已实现行为 | 主要位置 |
|---|---|---|
| 看清函数调用 | 项目内可解析调用图、调用者与被调用者、条件和源码定位；未知目标保留 | understanding.py、CallGraph.vue |
| 知道模块用途 | 阅读总览、模块与函数详情、文档字符串与命名线索、跨模块阅读路线 | understanding.py、manual.py |
| 理清变量变化 | 分作用域的参数绑定、赋值、覆盖、累加、容器修改与条件；不假装实时执行值 | understanding.py、变量变化页 |
| 给小白的长说明 | 先连贯解释目标、入口、数据流和具体输入推演，后附逐项结构索引；补充别名/闭包/生成器/协程语义 | manual.py、semantic_notes.py、manual_ai.py |
| 超过5000字生成Markdown | 大于5000非空白字符自动写入用户目录；5000与5001的边界测试通过，所有长度均可下载 | workbench_store.py |
| 目前只做Python，保留其它语言接口 | LanguageAdapter 注册协议；未启用语言明确拒绝 | languages.py |
| SQL 数据库 | 真正 SQLite 关系库：8张知识库表，另有任务/说明书/用量表；版本快照、事务索引、检索与差异 | knowledge.py、workbench_store.py |
| Vue 前端 | 本地构建静态资源，随安装包分发；无CDN、无需运行时Node | 前端功能/web |
| RAG | 当前版本 BM25、代码符号、调用关系检索 → 实际证据预览 → DeepSeek生成 → 引用编号检查 | retrieval.py、manual_ai.py |
| 可安装到另一台Windows | 自带Python运行时的独立EXE与Inno Setup安装包，旧版独立保留 | build_workbench.ps1 |

本版没有接入 MySQL、训练模型或语义向量库。它是通过 Windows 可执行程序启动的本地浏览器工作台；不是远程网站，也没有伪装成内嵌原生浏览器窗口。

- **10 个真实浏览器流程 + 1 个明确模拟的中断故障通过**：真实Edge浏览器操作导入、调用图点击、函数详情、变量定位、检索、长文生成与实际下载、AI发送前预览（取消，不收费）、版本差异、空首文件上传、密钥表单校验；无页面错误或失败HTTP。证据：`v02-ui-browser-results.json`、`v02-ui-*.png`。

## 4. 模拟盲评与迭代记录

题目作者未读取实现，先冻结5个Python项目与封存oracle。生成器仅读取题目，不读取oracle；输出冻结后由独立评阅者核对源码和oracle，并按事实准确30、调用流程20、变量条件20、小白可读性20、证据边界10评分。

这是分角色、隐藏参考答案与候选身份的**模拟盲评**。只有一个候选/每阶段、5个小样本，没有真人被试，不能叫真实人类双盲实验，分数也不是泛化准确率。首次评分之后的修改与再次评阅均明确属于已知样本回归。

| 阶段 | 结果与发现 |
|---|---|
| R17 初始离线说明 | 57.8/100；未确认事实错误，但固定输入、别名、闭包、延迟执行解释不足，说明很长仍不够易懂 |
| R23 非推理增强 | 84.66/100；发现协程被错误自动调度、打印字段和finally时序等实际错误，未作为合格最终结果 |
| R31 高推理与语义提示 | 四份完整说明；一份输出截断，保留静态结果及用量；完整/失败文档全部冻结 |
| R37 预算调整单例复验 | 截断样例重新生成成功，没有覆盖第一次记录 |
| R41 最终文档回归 | **92.6/100**；逐例95、92.9、91、89、95；35点中34完整、1部分，无阻断性错误。由R31的四份成功输出与R37的一份输出组成，不能据此宣称一次请求100%成功；详见 `其它/evaluation/v02_blind/最终说明匿名回归评分.md` |

冻结题目、承诺、三个阶段输出、全部评分及最终文档来源链均在 `其它/evaluation/v02_blind/`。旧0.1冻结测评未改动。最终评分仍只是这5份已知样本说明的静态质量评阅，不能替代真实用户理解测试。

最终材料冻结后，根据评阅发现，修正了静态模板的通用条件措辞：except/finally 可以在先前异常或准备return时进入，不应写成“前序没有异常或返回”。当前解析器与生成模板已更新，finally条件回归通过；冻结说明和评分不改写，保留原先扣分依据。模型章节仍可能有非阻断性表达问题或遗漏，详见最终评阅报告。

## 5. 发布核对与现有边界

最终产物以 `其它/安装包/ReviewDeskReading-0.2.0-*` 为准，旧 `ReviewDesk-0.1.0-*` 保留。发布检查包括ZIP CRC、三目录和Vue资源、禁入依赖/数据库/密钥、冻结字节码与源码模块一致、纯系统PATH解压运行，以及全release SHA-256。记录分别为 `v02-bundle-inspection.json`、`v02-prearchive-secret-scan.json` 和归档验证报告；最终校验值见安装包目录 `SHA256SUMS.txt`。

安装包约15.5 MiB，包含50项Python/前端/构建相关组件的许可文本和版本记录。最终具体尺寸与哈希以发布验证记录为准。

**尚未验证或不能保证的事项：**另一台实体电脑；真实新手阅读效率；任意规模Python仓库的完整理解；反射、猴子补丁、运行时类型分派、全部闭包关系；模型逐句正确性。变量界面展示可能发生的源码事件，不是运行时轨迹。源码只读静态分析，不运行不可信项目。

SQLite知识库会保存脱敏源码快照，自动脱敏不能识别所有敏感内容。大型项目最多500文件、单文件256 KiB/合计8 MiB，完整说明受文档容量保护，需要时按业务模块拆分。Java/JavaScript等仅预留适配协议，解析器未实现。
