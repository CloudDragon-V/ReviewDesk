# v0.2 后端与接口独立审计记录

日期：2026-09-20。范围：`workbench.py`、`workbench_store.py`、`manual_ai.py`、`web_api.py`、启动入口，以及 Vue 与这些 API 的字段契约。

这是实现后的独立代码审计与故障复现，不是双盲用户实验。所有模型调用均为 mock；没有发起真实 DeepSeek 请求或消耗额度。临时 SQLite 数据只包含人为编写的演示程序。

## 发现与修复复验

| 发现 | 复现与影响 | 复验结果 |
| --- | --- | --- |
| 前端未发送 `preview_id` | 预览接口 200，按原前端载荷发起生成得到 400，付费讲解入口无法使用 | 前端现先捕获 `preview_id` 再启动任务，代码检查已对齐；完整浏览器验证由主任务进行 |
| 关键词策略值错误 | 原前端发送 `lexical`，后端仅接受 `keyword`、`hybrid`、`dependency`，返回 400 | 前端已改为 `keyword` |
| 上传首个文件为空时拒绝整个项目 | 普通 Python 包的空 `__init__.py` 被当作没有上传代码 | 前端现仅在粘贴模式禁止空内容，上传模式允许空文件 |
| 中断任务状态未列为终态 | `interrupted` 会继续轮询，直至 20 分钟超时 | 前端现将 `interrupted` 显示为终止失败 |
| 非 ASCII token 造成异常 | 测试头字节 `0xe9` 使原 `hmac.compare_digest` 抛出异常，返回 500 | 现在返回 403；畸形 Host 也返回 403 |
| 删除文件失败后丢失清理身份 | 模拟导出文件被独占打开：原实现已删除项目及说明书元数据，却遗留 Markdown，重试只能提示项目不存在 | 现在先清文件，失败保留项目和说明书元数据；解除模拟锁后重试完整删除成功 |
| Python 物理行号与检索片段错位 | 字符串含 U+2028 时，AST 函数 L2–3 原检索返回字符串末尾与函数声明，遗漏 return | 知识库、diff 与分析器现统一物理行；22 项知识库测试通过，包含 U+2028/U+2029/换页/垂直制表符回归 |
| 长文档容量检查发生在模型请求后 | 原代码在请求后才检查 200 万字符存储限制，存在收费后无法保存风险 | 当前 99,779 字节/2000 函数的合法输入，在请求前明确拒绝过大说明；mock 调用次数为 0 |
| 每个符号重复对整文件脱敏 | 一个约 100 KB 文件、2000 个函数的预览曾持续数十秒；每个候选重复生成脱敏行表 | 按文件缓存后同一测试预览为 0.327 秒；这是当前机器单次观测，并非性能基准 |
| 用量展示字段与未知状态不一致 | `cost_cny` 与实际字段 `estimated_cost_cny` 不符；`actual=False` 的默认 0/0 容易误呈现为零消耗 | 已反馈主任务修正前端；此记录不将未完成的浏览器复验算作通过 |

## 已实际验证的正常边界

- 无会话 token 请求受保护 API：403。
- 其他 Origin 发起请求：403。
- 声明 13 MiB 请求体：413。
- mock 模型调用收到的代码上下文与预览上下文逐字符一致。
- 同一预览标识只可确认一次，重放被拒绝。
- 模型模拟失败只调用一次，不自动重试；静态说明仍保存，说明状态为 `partial`，mock 返回的真实用量字段仍被保留。
- 超过 5000 个非空白字符的说明会生成 UTF-8 Markdown；磁盘文件与 API 返回的 Markdown 逐字符一致。
- SQLite 项目、版本、源码、符号、调用、代码单元、词法索引独立持久化；版本隔离、幂等导入、多线程访问、故障回滚、删除中的一致快照读取等 22 项测试通过。

## 验证边界

没有通过真实外部模型检验解释质量，没有运行真实付费调用，没有将模拟用量当作实际费用。此次审计也不能替代目标 Windows 机器的安装和浏览器操作验证。词法 BM25、符号与静态调用扩展是当前检索方法，没有训练或调用语义嵌入模型。
