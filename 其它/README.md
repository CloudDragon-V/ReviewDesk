## 第一次使用

1. 双击安装包，安装后打开“ReviewDesk 阅读工作台”，等待默认浏览器显示本机页面。
2. 点击“载入示例”体验三文件购物订单；或点击“导入 Python 项目”，选择 `.py` 文件、填写本机目录，或粘贴代码。目录导入更适合保留包结构。
3. 从“阅读总览”的程序入口开始。点击文件、函数或行号，可在右侧查看对应源码。
4. 用“函数调用”查看关系，用“模块与函数”阅读参数、执行步骤和返回路径，用“变量变化”按名称和作用域查看赋值、累加、容器修改及其条件。
5. 在“详细说明书”先生成离线说明书，它逐章展开已解析代码结构，不限于几条审查意见。
6. 在“模型与设置”填写密钥；需要 DeepSeek 时，先预览实际发送的代码范围和费用，确认后生成。不会自动重试收费请求。
7. 超过 **5000 个非空白字符**时，后台自动保存 `.md`，页面显示文档位置。任何长度均可“下载完整 Markdown”，分段阅读不影响全文下载。
8. 用完后在“模型与设置”点击“退出本地后台”，再关闭标签页。只关闭标签页会保留服务；再次双击快捷方式可返回同一工作台。

## 各页面与操作

| 页面或操作 | 用途 |
|---|---|
| 阅读总览 | 文件、代码单元、入口、模块分工、本地检查问题；不执行项目代码 |
| 函数调用 | 静态调用图、缩放、定位调用方和目标；无法确定的调用明确标记 |
| 模块与函数 | 按名称/文件筛选，查看签名、参数、条件步骤、返回、调用者和被调用者 |
| 变量变化 | 按名称/作用域查看事件；不同作用域的同名变量分开，行号可定位 |
| 详细说明书 | 生成、保存、重读、下载长文；模型失败保留静态说明和已知用量 |
| 知识检索 | 在当前版本按关键词、符号、调用关系查找代码，显示片段、行号与理由 |
| 版本对比 | 同名项目新导入保留版本；比较新增、删除、修改及内容一致的一对一改名 |
| 模型与设置 | 密钥、是否安全记住、运行边界、退出后台 |
| 删除项目 | 经确认后删除本机该项目的版本、索引、已保存说明书；不删除原始源码 |

自动文档默认位置：`%LOCALAPPDATA%\ReviewDesk\manuals\代码说明书_<编号>.md`。5000 字按非空白 Unicode 字符计数，包含标点、代码、Markdown 标记，不等于汉字数或模型 token。恰好 5000 不触发自动保存，5001 才触发；两者都能手动下载。

## 说明书与实际运行的区别

离线说明覆盖入口、模块关系、函数签名与用途线索、执行结构、返回值、调用、变量事件和静态问题。模型以实际检索到的源码为依据，补充连贯的中文因果解释。示例约 1.9 万字符，包含真实模型生成的业务说明、金额推演、逐章引用。

变量追踪是**静态事件分析**，例如“满足条件时执行 `subtotal += amount`”，不是执行后采集的实时值。系统不执行、不导入、不改写被分析项目；模型举例必须区分静态推演与实际输出。

动态派发、反射、猴子补丁、继承重写、闭包及外部调用不能保证完全还原。文档字符串属于作者声明，函数名只是用途线索。引用编号经过检查，但模型文字仍需对照源码，不能作为程序正确性的证明。

目前仅内置 **Python**；`后端功能/reviewdesk/languages.py` 保留语言适配接口。其它语言需要真实解析器、结构映射与测试，尚未实现。

## SQL、Vue、RAG 的实际范围

- **SQL：**实际使用 SQLite，保存项目、不可变版本、脱敏源码、符号、调用、代码片段、倒排索引、任务和说明书。没有宣称接入 MySQL。
- **Vue：**生产静态文件随安装包分发，无在线 CDN 依赖。界面访问只监听 `127.0.0.1` 的本机服务。
- **RAG：**版本内 BM25 关键词、代码标识符、调用关系检索，再交给 DeepSeek 依据证据讲解。没有使用预训练向量嵌入、FAISS、Chroma 或向量数据库。
- **数据：**新版保存脱敏后的完整源码快照：`knowledge.db` 为知识库，`workbench.db` 为任务和说明书，旧 `reviews.db` 保留。自动脱敏仅覆盖常见模式，发送前应检查预览。
- **密钥：**选择记住时保存到 Windows 凭据管理器，否则只在进程内使用；API 不返回密钥，交付包不携带开发密钥。

单次默认费用上限 ¥0.20，预检超额拒绝发送。token 使用 API 返回值，人民币为估算，以平台账单为准；缺少用量显示未知，不假装实际零消耗。价格核对来源：[DeepSeek 官方价格文档](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)，核对日期 2026-09-20。

详细讲解启用 high 推理模式，并附带源码对应的 Python 语义提示；思考和最终输出共用本次输出预算，用量包含 API 返回的全部输出 token。界面只保存最终说明，不展示内部推理内容。仍需核对结论，启用推理并不保证无错。参数依据：[DeepSeek 思考模式官方文档](https://api-docs.deepseek.com/zh-cn/guides/thinking_mode/)。

## 容量与恢复

后台最多导入 500 文件，单文件 256 KiB、合计 8 MiB；网页文件选择器一次最多 300 文件。默认跳过常见虚拟环境、生成目录与符号链接。大仓库建议按业务模块导入。

单文档约 200 万原始字符容量保护；静态文档过大或没有空间追加模型章节，会在收费请求前提示分模块。页面约 6 万字符以上分段渲染，全文照常保存和下载。

后台重启会标记中断任务，不自动补发 API；模型失败保留静态说明。顶部“近期任务与中断记录”可查看状态、错误和实际/未知用量。说明书正文与用量先保存到SQLite，再写Markdown文件；文件导出失败仍可下载正文或点击“重试保存文件（不调用模型）”。数据库本身不可写时不能保证保存新正文。删除文档被占用时保留数据库记录，解锁后可重试。
